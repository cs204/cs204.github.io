Бинарная классификация табличных данных - прогнозирование сердечных заболеваний.

Шаги выполнения

Зайдите на cs50.dev. Закачайте архив 

wget https://cs204.github.io/psets/data/heart.zip
Разархивируйте 

unzip heart.zip
Перейдите в каталог 

cd heart
Установите пакет 

sudo apt install graphviz
Создайте виртуальное окружение 

python -m venv ~/.venv
source ~/.venv/bin/activate
Установите нужные для проекта пакет 

pip install --upgrade pip
pip install -r requirements.txt
Запустите jupyter lab 

jupyter lab
Создайте порт 8888, откройте в браузере, используя токен, сгенерированный в терминале.

Создание собственного решения

Создайте файл heart.ipynb Откройте файл. Напишите собственный код на основе примера (example.ipynb). Разберите все команды. Вы можете проверить правильность выполнения задания, выполнив команду: 
npx cs204 2026/heart local
Для отправки на проверку выполните команду: 
npx cs204 2026/heart
Чтобы закрыть виртуальную среду, выполните команду: 
deactivate
