Emojize

Эмодзи определены Консорциумом Юникод. Функция emoji.emojize(s) - возвращает строку в которой вместо коротких названий подставляются сами эмодзи. 

>>> import emoji
>>> print(emoji.emojize("Python is :thumbs_up:")
Python is 👍
Список названий можно посмотреть здесь. Документация на пакет emoji.
В файле emojize.py реализуйте программу, приглашает ввести строку (input("Input: ")), и затем выводит строку с заменёнными названиями на эмодзи (print(f"Output: {s}")).
Подсказка
  • Напоминаем, что для инсталляции пакета emoji вам надо выполнить в терминале: 
    			
			pip install emoji

Шаги выполнения

Зайдите на cs50.dev. Используя команду cd, сделайте рабочим каталогом codespace. Создайте каталог emojize, выполнив 
mkdir emojize
Перейдите в каталог. 
cd emojize
Выполните 

code emojize.py
чтобы открыть редактор, и напишите вашу программу.
